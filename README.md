# Yamp

Yet Another Music Player — a simple local music player for Android built with Flutter.

## Links

- **Play Store:** [Download Yamp](https://play.google.com/store/apps/details?id=com.system74.yamp)

## Features

- Play songs from your device library
- Browse songs, albums, and playlists
- Queue, shuffle, and repeat
- Background playback with lock-screen / notification controls
- Search songs and albums
- Light / dark theme
