# Release notes

## v1.0.0

First release of **Yamp** (Yet Another Music Player).

### What's included

- Now playing screen with seek, next / previous
- Songs, albums, and playlists browsing
- Play from library, album, playlist, or search
- Shuffle and repeat (off / all / one)
- Background playback
- Media notification and lock-screen controls
- Search for songs and albums
- Theme mode and accent color settings
- Restores last played track and position
